A short course for researchers

The Agentic Researcher

You became a researcher to answer questions, but you spend much of your week on other work: cleaning the same data again, pasting tables into Word, hunting for the one number that changed, rebuilding a figure for a reviewer two years later.

AI agents can now do much of that mechanical work inside your own project, while you keep the parts that need a researcher: the question, the design, and what the results mean. Done well, it makes your work more trustworthy, not less. Every number comes from code you can run again, and every change the agent makes is recorded for you to read, so you can always show how a result was made.

If you already use AI and aren’t sure where the lines are, you’re not alone, and you don’t need to hide it. Start with what an agent is, what to keep for yourself, and how to work with one in a way you can defend. Then, when you’re ready, set up a computer built for this way of working.

You’ll need: curiosity and a Claude subscription to start; later, a computer you can give to Linux, a USB stick and an afternoon
You won’t need: to know how to program, or to have used Linux before
